# Розробка MVP застосунку для навчання читанню (за методикою В. Федієнка)

Цей репозиторій містить програмний код прототипу (MVP) та дослідницькі скрипти (R&D), створені в рамках магістерського проєкту (напрям DS&DA). Мета проєкту — розробка інтерактивного середовища для автоматичної верифікації дитячого мовлення (ізольованих фонем та складів) під час навчання читанню українською мовою.

## Архітектурна еволюція та R&D експерименти (Model Benchmarking)

Під час розробки MVP було проведено масштабне тестування різних підходів машинного навчання (Data-Driven підхід). За результатами експериментів прийнято такі архітектурні рішення:

1. **ASR Моделі (Whisper):** Відхилено. Модель оптимізована для суцільного тексту і схильна до "додумування" цілих слів замість розпізнавання ізольованих фонем дитячого мовлення.
2. **Екстракція ознак YAMNet:** Відхилено (Dependency Hell). Виявлено критичну технологічну нестабільність через конфлікт застарілого API `tensorflow_hub` із сучасним ядром TensorFlow 2.16+.
3. **Фонемні моделі (Wav2Vec2Phoneme):** Відхилено. Згідно з документацією, модель не підтримує складову токенізацію, що порушує бізнес-логіку методики Федієнка (злиття у склади).
4. **Оптимізація розмірності векторів (PCA):** Відхилено. Стиснення векторів зі 1024 до 128/512 ознак обвалило точність з 79% до 66-68%. Збережено повну розмірність (1024) для фіксації тонких акустичних нюансів.
5. **ФІНАЛЬНЕ РІШЕННЯ:** **Wav2Vec 2.0 (XLSR-53 Ukrainian) + Support Vector Machine (SVM)**. 
   * **Дані:** Завдяки розширеній аугментації в Librosa (Uniform/Gaussian noise, pitch shift, time stretch) датасет збільшено до 5728 записів.
   * **Класифікатор:** SVM із лінійним ядром продемонстрував точність **82.9%**, перевершивши Random Forest (64.8%) та MLP (який не зійшовся за 500 ітерацій).
   * **UX/UI:** Графічний інтерфейс MVP реалізовано на фреймворку **Flet** із динамічною анімацією та логікою прийняття рішень на основі `predict_proba`.

## Структура репозиторію

### Основний застосунок (MVP)
* `ui_app1.py` — головний файл інтерактивного застосунку на базі фреймворку Flet (містить логіку букварного періоду, анімації Капітошки, запис мікрофона та інтеграцію ML-пайплайну).
* `convert_audio.py` — скрипт низькорівневої конвертації диктофонних записів `.m4a` у необхідний формат (16 kHz, Mono) за допомогою системного кодека FFmpeg.
* `assets/` — директорія з графічними та аудіоматеріалами для інтерфейсу.

### Дослідницькі скрипти (R&D)
* `augment_data.py` — скрипт DSP-аугментації даних (білий шум з різними розподілами, зміна швидкості та тону).
* Скрипти бенчмаркінгу: `train_rf.py` (Random Forest), `train_logreg.py` (Логістична регресія), `train_mlp.py` (Multi-Layer Perceptron), `train_pca.py` (дослідження розмірності векторів).
* `test_whisper.py` / `batch_test_whisper.py` — скрипти тестування ASR-підходу.
* `*.csv` — артефакти експериментів (результати порівнянь, оцінка точності моделей).

   pip install flet librosa torch transformers scikit-learn numpy joblib

   Системні вимоги: Для коректної роботи мікрофона та конвертації переконайтеся, що у системі встановлено FFmpeg.

Запуск застосунку:
У кореневій директорії проєкту виконайте команду:

Bash
python ui_app1.py
Відкриється настільне вікно застосунку. Натисніть кнопку мікрофона (пульсуюча іконка), щоб розпочати взаємодію.
