# Тестування ASR моделей для дитячого мовлення (MVP)

Цей репозиторій містить експериментальні скрипти для перевірки здатності переднавчених моделей розпізнавати ізольовані українські фонеми та склади, вимовлені дитиною (вік 4 роки). Дослідження проводиться в рамках магістерського проєкту зі створення вебзастосунку для навчання читанню.

## Вміст репозиторію:
1. `batch_test_whisper.py` — пакетне тестування аудіофайлів за допомогою моделі OpenAI Whisper. Містить функцію нормалізації тексту (видалення пунктуації та дублювань літер).
2. `test_wav2vec.py` — пакетне тестування за допомогою акустичної моделі Meta Wav2Vec 2.0 (українська версія).
3. `calculate_metrics.py` — скрипт для порівняння розпізнаного тексту з еталонним (Ground Truth) та розрахунку метрики Accuracy.
4. `*.csv` файли — результати тестування та аналіз систематичних помилок моделей.

## Ключові висновки експерименту:
* Whisper ('small') показав точність **66.7%**.
* Wav2Vec 2.0 показав точність **51.9%**.
* Обидві моделі мають значні проблеми з розпізнаванням ізольованих приголосних через специфіку дитячої вимови та архітектурну схильність LLM до "додумування" слів з окремих фонем.
* **Наступний крок розробки:** Перехід від Speech-to-Text до математичного порівняння аудіовекторів (Feature extraction) за допомогою бібліотеки `librosa` та косинусної подібності.
