# Розробка MVP застосунку для оцінювання правильності вимови у дітей (за методикою В. Федієнка)

Цей репозиторій містить програмний код прототипу (MVP) та дослідницькі скрипти (R&D), створені в рамках магістерського проєкту (напрям DS&DA). Мета проєкту — розробка системи автоматичної верифікації дитячого мовлення (ізольованих фонем та складів-злиттів) під час навчання читанню.

## Архітектурна еволюція та R&D експерименти
Під час розробки MVP було проведено масштабне тестування різних підходів машинного навчання. За результатами експериментів (Model Selection) було прийнято наступні архітектурні рішення:

1. **ASR Моделі (Whisper):** *Відхилено.* Модель оптимізована для суцільного тексту і схильна до "додумування" цілих слів замість розпізнавання ізольованих фонем дитячого мовлення.
2. **Багатокласова класифікація (SVM):** *Відхилено для MVP.* Було проведено аугментацію даних (Pitch Shifting, Time Stretching) до 630 аудіофайлів та натреновано класифікатор на 60 класів. Проте на малих вибірках модель продемонструвала схильність до перенавчання (Overfitting) на мікрошумах мікрофона під час роботи наживо.
3. **Екстракція ознак YAMNet:** *Відхилено (Dependency Hell).* Виявлено критичну технологічну нестабільність моделі через конфлікт застарілого API `tensorflow_hub` (Keras 2) із сучасним ядром TensorFlow 2.16+ та Python 3.12+, що унеможливлює безпечне розгортання в Production.
4. **ФІНАЛЬНЕ РІШЕННЯ (Data-Driven MVP):** **Wav2Vec 2.0 (XLSR-53 Ukrainian) + Cosine Similarity + Гранульовані пороги.** Система витягує фонетичні ембединги (1024-вимірні вектори) та порівнює їхню геометричну подібність. Для компенсації різниці між дитячим і дорослим тембрами використовуються індивідуальні математичні пороги для кожного з 60 звуків.

## Структура репозиторію

### Основний застосунок (MVP)
* `main.py` — бекенд застосунку на базі FastAPI (інтеграція Wav2Vec 2.0 та перевірка косинусної подібності).
* `index.html` — клієнтський веб-інтерфейс для взаємодії з користувачем (дитиною).
* `thresholds_report.csv` — ключова матриця індивідуальних математичних порогів відсікання для кожного звуку.

### Дослідницькі скрипти (R&D)
* `find_thresholds.py` — скрипт автоматичного розрахунку оптимальних порогів (Data-Driven Thresholds).
* `augment_data.py` — скрипт DSP-аугментації даних (зміна швидкості, тону, додавання шуму) за допомогою `librosa`.
* `train_model.py` — скрипт екстракції векторів та тренування SVM-класифікатора.
* `test_yamnet.py` — скрипт-фіксатор архітектурної несумісності бібліотеки TensorFlow Hub.
* `test_whisper.py` / `batch_test_whisper.py` — скрипти тестування ASR-підходу.
* `*.csv` — артефакти експериментів (результати порівнянь, оцінка точності моделей).
