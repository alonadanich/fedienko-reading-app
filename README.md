# Вчимося читати з Капітошкою

**Кросплатформений програмний засіб із трирівневим ML-ядром для самостійного навчання читанню дітей віком від 4 років українською мовою за звуко-складовою методикою Василя Федієнка.**

Застосунок охоплює початковий букварний цикл — від вивчення ізольованих фонем до злитого читання відкритих і закритих складів, коротких слів та ілюстрованих речень-ребусів — з автоматизованою перевіркою вимови в реальному часі та повним озвученням живим дитячим голосом.

---

## Основні функціональні компоненти

* **10 навчальних рівнів («замочків»: А, У, О, М, Н, И, І, С, Л, К):** реалізовані на основі *Data-Driven UI* із фонетичним кольоровим кодуванням (голосні — червоним, приголосні — синім).
* **Двофазна структура заняття:** вправа на розвиток фонематичного слуху («Обери слово») та інтерактивний голосовий тренажер читання.
* **Трирівневий маршрутизатор моделей (`Tri-level Model Routing`):** автоматично скеровує нормалізований аудіосигнал (16 кГц) до спеціалізованої моделі залежно від довжини цільової мовленнєвої одиниці, блокує реверсивне читання складів справа наліво (`ау` замість `уа`) та компенсує дитячі паузи між складами.
* **Дослідницька панель «Керування 3 моделями та доступом»:** забезпечує динамічне підключення зовнішніх моделей у форматах **Scikit-learn (`.pkl`)**, **Keras 3 (`.keras` поверх PyTorch)** і **Hugging Face (`Wav2Vec2ForSequenceClassification` / `Wav2Vec2ForCTC`)**, зміну базового екстрактора `Wav2Vec 2.0` та вибір прихованого шару без модифікації програмного коду.

---

## Архітектура ML-ядра та результати валідації

Система використовує спільний базовий трансформер (`anton-l/wav2vec2-large-xlsr-53-ukrainian`) у режимі **Shared Backbone**. Оцінювання виконано за протоколом ізоляції дикторів **Speaker-Independent (`GroupKFold`, 5 фолдів)** на корпусі з **5728 аудіозаписів** (63 фонетичні класи від 13 дикторів):

| Рівень маршрутизатора | Мовленнєва одиниця | Конфігурація моделі | Точність (GroupKFold) | Обсяг файлу (`.keras` / `.pkl`) |
| :--- | :--- | :--- | :---: | :---: |
| **Рівень 1 (`letters`)** | Ізольовані фонеми (1 звук) | `Wav2Vec 2.0` (Шар `L8`, Mean Pooling) + `MLP (256)` | **81,67%** | **1,03 МБ** / 4,08 МБ |
| **Рівень 2 (`syllables`)** | Двобуквені склади (2 звуки) | `Wav2Vec 2.0` (Шар `L12`, Temporal Pooling ×3) + `MLP (512-256-128, tanh)` | **66,04%** | **6,68 МБ** / 20,04 МБ |
| **Рівень 3 (`words`)** | Слова та речення (3+ літер) | `Wav2Vec2ForCTC` + нормалізація рядків + `Fuzzy Matching` | Посимвольна транскрипція | Спільне ядро (~1205 МБ у кеші HF) |

## Авторський аудіокорпус дитячого мовлення (Dataset)

У межах проєкту сформовано та верифіковано спеціалізований набір даних для задачі класифікації українських фонем і складів дитячого мовлення:
* **Обсяг корпусу:** 5728 аудіозаписів у форматі WAV (16 кГц, Mono), отриманих шляхом запису та контрольованої акустичної аугментації.
* **Структура:** 63 фонетичні класи базового букварного періоду (10 ізольованих звуків та 53 відкриті й закриті двобуквені склади) від **13 дітей-дикторів** (розмітка за `speaker_id` для `Speaker-Independent` валідації).
* **Відкритий доступ до набору даних:** [Завантажити аудіокорпус з Google Drive](ВСТАВТЕ_ПОСИЛАННЯ_ІЗ_dataset_augmented_zip.txt)

## Встановлення та запуск

1. Клонуйте репозиторій та встановіть залежності (підтримується Python 3.10 – 3.14):
```bash
git clone [https://github.com/alonadanich/fedienko-reading-app.git](https://github.com/alonadanich/fedienko-reading-app.git)
cd fedienko-reading-app
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

2. Завантажте зовнішні ресурси за посиланнями у відповідних текстових файлах репозиторію:
* **Медіаасети інтерфейсу та озвучення:** розпакуйте архів із `assets/assets_zip.txt` у папку `assets/`.
* **Серіалізовані ваги моделей (`.keras` та `.pkl`):** завантажте за посиланням у файлі `Kapitoshka_Models.txt` у корінь проєкту або підключіть із довільної директорії на ПК у вкладці **«Керування 3 моделями та доступом»**.

3. Запустіть застосунок:
* **Десктопний режим:** `python main.py`
* **Вебрежим у браузері:** `flet run --web main.py`
