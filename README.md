# Вчимося читати з Капітошкою 

**Кросплатформений освітній тренажер із трирівневим ML-ядром для самостійного навчання читанню дітей віком від 4 років українською мовою за звуко-складовою методикою Василя Федієнка.**

Застосунок супроводжує дитину на всьому початковому букварному шляху — від знайомства з першими ізольованими звуками до злитого читання відкритих і закритих складів, перших слів та ілюстрованих речень-ребусів — з автоматичною перевіркою вимови в реальному часі та повним автентичним озвученням живим дитячим голосом.

---

## Основні можливості

* **10 навчальних рівнів («замочків»: А, У, О, М, Н, И, І, С, Л, К):** побудовані за принципом *Data-Driven UI* із дотриманням фонетичного кольорового кодування (голосні — червоні, приголосні — сині).
* **Двофазна методика кожного заняття:**
  1. *Розвиток фонематичного слуху* — інтерактивна гра «Обери слово» з ілюстрованими картками.
  2. *Голосовий тренажер читання* — поступовий перехід від поодиноких звуків до двобуквених складів, трибуквених злиттів із роздільною лінією (`лі┆с`, `на┆с`), слів та речень-ребусів.
* **Автентичний дитячий UX:** усі інструкції, підказки та мотивуючі репліки персонажа Капітошки на всіх 10 рівнях озвучені живим дитячим голосом; реалізовано синхронну анімацію вказівного пальчика зліва направо та автоматичне блокування мікрофона під час звучання підказок.
* **Трирівневий маршрутизатор моделей (`Tri-level Model Routing`):** автоматично скеровує аудіозапис (16 кГц) до спеціалізованої моделі залежно від фонетичної структури завдання, блокує реверсивне читання складів справа наліво (`ау` замість `уа`) та компенсує дитячі паузи між складами.
* **Дослідницька панель «⚙️ Керування 3 моделями та доступом»:** дозволяє без модифікації програмного коду та без перезапуску вікна підключати із зовнішніх папок моделі у форматах **Scikit-learn (`.pkl`)**, **Keras 3 (`.keras` поверх PyTorch)** і **Hugging Face (`Wav2Vec2ForSequenceClassification` / `Wav2Vec2ForCTC`)**, змінювати базовий екстрактор `Wav2Vec 2.0` і перемикати приховані шари трансформера.
* **Підтримка Desktop та Web:** працює як нативний десктопний застосунок та у веббраузері на базі фреймворку `Flet`.

## Архітектура ML-ядра та результати валідації

Система використовує спільне акустичне ядро **Shared Backbone** (`anton-l/wav2vec2-large-xlsr-53-ukrainian`), яке завантажується в оперативну пам'ять один раз і обслуговує три рівні розпізнавання. Оцінювання виконано за суворим протоколом **Speaker-Independent (`GroupKFold`, 5 фолдів)** без витоку тембру диктора на корпусі з **5728 аудіозаписів** (63 фонетичні класи від 13 дітей):

| Рівень маршрутизатора | Мовленнєва одиниця | Конфігурація моделі | Speaker-Independent точність | Обсяг файлу (`.keras` / `.pkl`) |
| :--- | :--- | :--- | :---: | :---: |
| **Рівень 1 (`letters`)** | Ізольовані фонеми (1 звук) | `Wav2Vec 2.0` (Шар `L8`, Mean Pooling) + `MLP (256)` | **81,67%** | **1,03 МБ** / 4,08 МБ |
| **Рівень 2 (`syllables`)** | Відкриті й закриті склади (2 звуки) | `Wav2Vec 2.0` (Шар `L12`, Temporal Pooling ×3) + `MLP (512-256-128, tanh)` | **66,04%** | **6,68 МБ** / 20,04 МБ |
| **Рівень 3 (`words`)** | Слова та речення (3+ літер) | `Wav2Vec2ForCTC` + нормалізація рядків + `Fuzzy Matching` | Посимвольна транскрипція | Спільне ядро (~1205 МБ у кеші HF) |

> **Порівняння з базовими підходами на тих самих 5 фолдах `GroupKFold`:**
> * Штатний `Wav2Vec2ForCTC` без донавчання («з коробки»): **12,64%** (звуки) та **19,41%** (склади).
> * Штатний `Wav2Vec2ForSequenceClassification` із донавчанням голови та зважуванням усіх 25 шарів (`use_weighted_layer_sum=True`): **77,90%** (звуки) та **64,51%** (склади) при обсязі **1204,37 МБ** на одну модель.
> * Середній час інференсу 1 с аудіо на звичайному CPU (без GPU): **354–436 мс**.

## Структура проєкту

```text
├── assets/                       # Ілюстрації (.png), стани Капітошки та дитяча озвучка (.wav)
├── experiments/                  # Скрипти навчання, крос-валідації GroupKFold та бенчмарків
│   ├── benchmark_and_export.py   # Експорт у формат .keras та профілювання ваги/швидкодії
│   ├── benchmark_split_sounds.py # Пошаровий бенчмаркінг звуків і складів (L8, L12, L16, L20)
│   ├── run_table_4_2_experiments.py # Порівняння зі штатними моделями Hugging Face (5-fold CV)
│   ├── train_singles_model.py    # Навчання класифікатора ізольованих звуків (Шар 8 + MLP)
│   └── train_ultimate_pairs.py   # Дослідження багатошарових ознак і тюнінг класифікатора складів
├── main.py                       # Точка входу: головна мапа 10 замочків та вкладка керування ML
├── level_engine.py               # Універсальний ігровий рушій та модуль запису DirectMicRecorder
├── levels_config.py              # Конфігурація всіх 10 рівнів, карток слів і вправ букваря
├── model_manager.py              # Поліморфний трирівневий маршрутизатор (.pkl / .keras / HF)
├── requirements.txt              # Перелік необхідних Python-пакетів
└── README.md                     # Документація проєкту
```

## Встановлення та швидкий старт

### 1. Підготовка середовища
Проєкт підтримує **Python 3.10 – 3.14** (ОС Windows, macOS, Linux). Клонуйте репозиторій та встановіть залежності:

```bash
git clone [https://github.com/alonadanich/fedienko-reading-app.git](https://github.com/alonadanich/fedienko-reading-app.git)
cd fedienko-reading-app
python -m venv .venv
```

Активація віртуального середовища та встановлення бібліотек:
* **Windows (PowerShell):**
  ```powershell
  .venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  ```
* **Linux / macOS:**
  ```bash
  source .venv/bin/activate
  pip install -r requirements.txt
  ```

### 2. Завантаження навчених моделей (зовнішнє сховище)
Відповідно до принципів розділення вихідного коду та бінарних ML-артефактів, навчені класифікатори розміщено у хмарному сховищі:

 **[Завантажити моделі (.keras та .pkl) з Google Drive](ВСТАВТЕ_ПОСИЛАННЯ_НА_GOOGLE_DRIVE)**

* **Варіант А (швидкий старт за замовчуванням):** покладіть файли `model_mlp_singles.pkl`, `scaler_singles.pkl`, `le_singles.pkl`, `model_mlp_pairs.pkl`, `scaler_pairs.pkl`, `le_pairs.pkl` у кореневу папку проєкту.
* **Варіант Б (зовнішнє підключення будь-якого формату):** збережіть моделі (зокрема компактні `.keras` сумарною вагою **7,71 МБ** або власну модель `Hugging Face`) у довільну папку на комп'ютері, запустіть програму, відкрийте вкладку **« Керування 3 моделями та доступом»**, оберіть потрібні файли через діалог `` та натисніть **« Застосувати моделі»**. Налаштування автоматично збережуться у `model_config.json`.

*(Базова модель `anton-l/wav2vec2-large-xlsr-53-ukrainian` автоматично завантажиться з Hugging Face Hub під час першого запуску).*

### 3. Запуск застосунку

* **Десктопний режим (рекомендовано для роботи з файловим діалогом моделей):**
  ```bash
  python main.py
  ```
* **Вебрежим у браузері:**
  ```bash
  flet run --web main.py
  ```
