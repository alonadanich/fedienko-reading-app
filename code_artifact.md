# Розробка MVP застосунку для навчання читанню за методикою В. Федієнка

Цей репозиторій містить програмний код прототипу (MVP), навчені моделі та дослідницькі скрипти (R&D), створені в рамках магістерського проєкту (напрям DS&DA). Мета проєкту — розробка інтерактивного AI-середовища «Вчимося читати з Капітошкою» для самостійного навчання дітей віком від 4 років читанню українською мовою (від ізольованих звуків і складів до перших слів та речень).

---

## Архітектурна еволюція та R&D експерименти (Model Benchmarking)

Розробка базувалася на Data-Centric підході (5728 аудіозаписів, 63 фонетичні класи, 13 унікальних дикторів) та суворому протоколі оцінювання **Speaker-Independent Split** (`GroupShuffleSplit` та 5-кратна крос-валідація `GroupKFold` за `speaker_id`), що повністю усуває витік даних за тембром дитини.

У ході 12 серій експериментів перевірено та відхилено нерелевантні підходи, на основі чого сформовано фінальну каскадну систему:

1. **Універсальні ASR для окремих звуків (Whisper) та YAMNet:** Відхилено на ранніх етапах через схильність мовних моделей «додумувати» слова на коротких дитячих фонемах та конфлікти залежностей застарілого `tensorflow_hub`.
2. **Міжнародні фонемні моделі (`wav2vec2-xlsr-53-espeak-cv-ft`):** Відхилено. Тестування показало нестабільність IPA-транскрипції на дитячих складах (втрата приголосних, інверсія порядку звуків при зміні темпу чи висоти тону).
3. **End-to-End Fine-Tuning (`Wav2Vec2ForSequenceClassification`):** Відхилено для малого корпусу. Повне донавчання трансформера протягом 3 епох призвело до ефекту катастрофічного забування (Catastrophic Forgetting) та падіння точності до **39.79%**.
4. **Пошаровий бенчмаркінг `Wav2Vec 2.0` та виявлення Data Leakage:** Аналіз внутрішніх представлень `anton-l/wav2vec2-large-xlsr-53-ukrainian` на випадковому поділі показав пік на **12-му шарі (91.80%)** проти 69.20% на CNN та 83.51% на фінальному 24-му шарі. Проте ізоляція незнайомих дітей у тестовій вибірці знизила результат базового лінійного SVM на 12-му шарі до чесних **61.40%**, виявивши запам'ятовування тембру при випадковому розбитті.
5. **Контрольні Speaker-Independent експерименти (негативні результати та фільтрація шуму):**
   * *Агресивний Silero VAD + сильний Pitch Shift (+4 півтони):* зниження точності до **59.40%** через обрізання тихих дитячих придихів і спотворення акустичних формант.
   * *Градієнтний бустинг (`CatBoost` + `SMOTETomek` + `PCA`):* **56.96%** на складах — ортогональні розрізи дерев рішень поступаються нейромережам на щільних неперервних ембеддінгах, а лінійна інтерполяція SMOTE породжує шум у латентному просторі.
   * *Злиття 12-го і 16-го шарів зі статистиками Mean/Std (12 288 ознак):* **64.93%** на складах через «прокляття розмірності» (стандартне відхилення фіксувало фонові шуми кімнати).
   * *Фільтрація тембру через `PCA(512)` + `SVM (RBF, C=10.0)`:* підвищення загальної чесної точності по всіх 63 класах до **63.40%**, а додавання часового розбиття (Temporal Pooling) з MLP — до **63.56%**.

## Фінальне архітектурне рішення (MVP Тижня 5)

У фінальному прототипі реалізовано **Трирівневу маршрутизацію моделей (Tri-level Model Routing)**, гібридний аудіопайплайн та масштабований **Data-Driven UI**:

* **Маршрут 1 — Ізольовані фонеми (Звуки):** Екстракція з **8-го шару** `Wav2Vec 2.0` (Mean Pooling, 1024 ознаки) + `StandardScaler` + `MLPClassifier (256)` — чесна Speaker-Independent точність **81.67%**.
* **Маршрут 2 — Відкриті та закриті склади (Парні звуки):** Екстракція з **12-го шару** `Wav2Vec 2.0` + **Temporal Pooling** (поділ на 3 часові сегменти для збереження динаміки переходу звуків, 3072 ознаки) + 3-шаровий `MLPClassifier (512-256-128, tanh, alpha=0.1)` — чесна Speaker-Independent точність **66.04%**.
* **Маршрут 3 — Перші слова та речення (Дисфлюентне читання):** Наскрізна модель `Wav2Vec2ForCTC` (автоматично згортає розтягнуті дитячі звуки) у парі з пост-процесором нормалізації тексту та алгоритмом нечіткого порівняння **Fuzzy Matching** (`SequenceMatcher`) для компенсації пауз між складами.
* **Гібридний синтез мовлення (Hybrid TTS Pipeline):** Живе дитяче озвучення на стартових рівнях 1–2 для формування емоційної довіри та динамічна генерація українського мовлення в реальному часі через `facebook/mms-tts-ukr` для масштабування рівнів 3–10.
* **Інтерактивний інтерфейс (Flet):** Централізована мапа з 10 навчальних «замочків» (А, У, О, М, Н, И, І, С, Л, К) із фонетичним кольоровим кодуванням (голосні — червоні, приголосні — сині), іграми на фонематичний слух, анімованим пальчиком для ведення погляду зліва направо, емоціями Капітошки та інтелектуальним блокуванням мікрофона.

## Структура репозиторію

### Клієнтський застосунок та маршрутизація (MVP)
* `main.py` — головна точка входу: інтерактивна мапа 10 рівнів («замочків») із перевіркою доступу та навігацією.
* `levels_config.py` — єдина Data-Driven конфігурація всіх 10 літер букваря В. Федієнка (кольори, словники ігор, вправи на читання складів, слів і речень).
* `audio_router.py` — модуль трирівневої ML-маршрутизації (`MLP Singles` / `MLP Pairs` / `Wav2Vec2ForCTC` + `Fuzzy Matching`) та гібридної TTS-озвучки (`mms-tts-ukr`).
* `ui_app1.py` — інтерактивний тренажер Рівня 1 (вивчення літери «А»).
* `level_u.py` — інтерактивний тренажер Рівня 2 (вивчення літери «У» та злиття перших складів «АУ», «УА»).
* `assets/` — директорія з підготовленими PNG-ілюстраціями для всіх 10 рівнів, станами персонажа Капітошки та студійними аудіозаписами.

### Збережені моделі (`.pkl`)
* `model_mlp_singles.pkl`, `scaler_singles.pkl`, `le_singles.pkl` — фінальний пайплайн для класифікації одиничних звуків (8-й шар).
* `model_mlp_pairs.pkl`, `scaler_pairs.pkl`, `le_pairs.pkl` — фінальний пайплайн для класифікації складів (12-й шар + Temporal Pooling).
* `fedienko_svm_model.pkl`, `label_encoder.pkl` — базова модель SVM (12-й шар) для автономного тестування прототипів рівнів.

### Дослідницькі скрипти (R&D стенд) та візуалізація
* `benchmark_layers.py` та `wav2vec_layers_benchmark.csv` — дослідження глибини шарів трансформера (CNN, 12, 18, 24).
* `benchmark_split_sounds.py` — роздільний Speaker-Independent бенчмаркінг шарів (8, 12, 16, 20) для ізольованих звуків та складів (`GroupKFold`).
* `train_singles_model.py` та `tune_pairs_model.py` — навчання експерта одиничних фонем і глибокий `GridSearchCV` тюнінг 3-шарового перцептрона для складів.
* `train_grouped.py`, `train_pro_hybrid.py`, `train_temporal.py`, `hyperparameter_tuning.py` — серія експериментів з усунення витоку даних, перевірки `Silero VAD`, `PCA + RBF SVM` та часового пулінгу.
* `train_wav2vec_finetune.py` — експеримент із повного End-to-End донавчання `Wav2Vec2ForSequenceClassification`.
* `test_phoneme_hybrid.py` — тестування міжнародної фонемної моделі з IPA-транскрипцією.
* `train_ultimate_pairs.py` та `train_catboost_pairs.py` — контрольні експерименти зі злиттям шарів на 12 288 ознак та конвеєром `CatBoost + SMOTETomek`.
* `train_model.py`, `train_logreg.py`, `train_mlp.py`, `train_pca.py` — базові скрипти порівняння класичних алгоритмів.
* `generate_thesis_charts.py` та `thesis_charts/` — генератор і збережені графіки високої роздільної здатності (300 DPI) для пояснювальної записки.

*(Примітка: сирий аудіодатасет `dataset_augmented/`, проміжні гігабайтні чекпойнти `best_wav2vec_model/` та кеші ознак `*_cache.pkl` виключені з репозиторію через обмеження розміру файлів GitHub та етичні норми зберігання дитячих голосів).*

## Інструкція із запуску локального застосунку

### 1. Системні вимоги
Переконайтеся, що у вашій операційній системі встановлено Python 3.10+ та системний аудіокодек **FFmpeg** (необхідний для коректної обробки записів мікрофона).

### 2. Встановлення залежностей
У кореневій папці проєкту виконайте команду:
```bash
pip install -r requirements.txt
```

### 3. Запуск застосунку
Щоб відкрити головне меню з інтерактивною мапою 10 замочків, виконайте:
```bash
python main.py
```

Для прямого запуску окремих демонстраційних рівнів тренажера можна також використати:
```bash
python ui_app1.py
python level_u.py
```
